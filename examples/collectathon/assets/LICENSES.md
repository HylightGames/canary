# Asset licenses

All files under `examples/collectathon/assets/` are MIT-licensed, same as
the Canary Engine repository itself (see the workspace root `LICENSE`),
except `pickup.wav`, which is dedicated to the public domain under
[CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/).

## Provenance

- `quad.glb`, `box.glb`: copied byte-for-byte from
  `engine/canary-assets/tests/fixtures/`. Those fixtures were generated by
  hand with a dependency-free Python script (no exporter, no toolchain
  behavior to drift) as documented in that directory's `README.md`:
  - `quad.glb`: one quad mesh (positions, texcoords, indices; no normals).
  - `box.glb`: one cube mesh in two primitives (normals + texcoords on the
    second).
- `sprites.png`: original to this example — one sprite atlas holding the
  player, a shard and the goal marker, drawn with a throwaway
  Python/Pillow script in `/tmp` (a 4x4 subpixel rasteriser writing a
  flat-colour PNG; the script is not part of the repository). 204x68
  8-bit RGBA: three 68px tiles, each holding one 64x64 sprite inset by
  2px. Every texel is opaque (the sample draws it through the unblended
  textured pipeline, so transparency would render as black) and every
  colour is flat, with no partial alpha. The shard and goal tiles paint
  the arena colour behind their icon so the opaque square disappears into
  the scene. MIT.
- `player_quad.glb`, `shard_quad.glb`, `goal_quad.glb`: original to this
  example — one unit quad each, generated by a throwaway Python script in
  `/tmp` (not part of the repository), with texcoords selecting that
  sprite's tile in `sprites.png`. Four vertices, six indices, no normals.
  MIT.
- `pickup.wav`: generated for this example with a throwaway Python stdlib
  script (`wave` + `math`), no third-party content: mono 16-bit PCM at
  48 kHz, 0.19 s, an 880 Hz sine with a 5 ms linear attack and exponential
  decay (τ ≈ 0.06 s), peak ≈ 0.85. CC0-1.0.
- `room.json`: original to this example — the seed room (player, three
  shards, goal) as an `AuthoredDocument` with `entity.<local>` sections.
- `guest.wat`: original to this example — the Tier A skeleton guest,
  shaped after the WAT patterns in
  `engine/canary-plugin-api/src/tier_a/tests.rs`.
