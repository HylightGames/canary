# Canary Engine `v0.0.12` — Release Notes

**Status:** released on `dev` as tag `v0.0.12` (2026-09-28).
**Scope source:** `docs/roadmap/v0.0.12-roadmap.md`
**Nature of this release:** the engine gains ears. `v0.0.12` gives
Canary sound-asset loading plus real audio playback — an `AudioSource`
component triggered by real game state, playing real sound assets
loaded via `v0.0.10`'s asset pipeline, through Canary's own trait
with a private `rodio` bootstrap backend.

## What `v0.0.12` is

- **WAV and Ogg Vorbis sound loading.** `Sound` (interleaved `f32`
  PCM, mono/stereo) decoded by pure-Rust `hound` + `lewton`
  (Symphonia declined on MPL-2.0 grounds), with bit-exact fixtures,
  file and decode budgets, and the same root confinement as every
  other loader.
- **`canary-audio`: trait + bootstrap backend.** An object-safe,
  leak-free `AudioBackend` trait (no third-party types in public
  signatures), minimal components (`AudioSource` trigger intent,
  `AudioListener`, system-owned voices, `AudioConfig`), and a
  private rodio 0.22.2 backend (decode-only MIT/Apache features;
  no-device operation degrades typed, never panics).
- **Scheduler-registered trigger system.** Game-state transitions
  become backend calls; removal/despawn reaps voices. Proven by a
  stub-backend game proof asserting exact call order — a second
  backend fits with zero API movement, by construction.
- **ADR 0023 accepted.** The rodio-bootstrap decision (custom
  in-house engine stays the long-term default) is recorded and
  accepted, not just implemented.

## What this release deliberately is not

- **Not a DSP graph, buses, or spatial audio.** No DSP graph, no
  buses, no HRTF/Doppler — each with an owning future; the custom
  engine stays the long-term default per ADR 0023.
- **Not audible-by-default output.** The bootstrap backend is
  decode-first; a host must insert a device backend for audible
  output. Headless operation (the CI configuration) degrades typed.
- **Not UI, state, or networking.** `v0.0.13` (CanaryUI + windowed
  presentation) is next and consumes this crate's trigger pattern
  for UI-driven sound.

## Try it

```sh
git clone <this repository>
cd canary
git checkout v0.0.12
cargo build --workspace
cargo test --workspace
```

## What's next: goals for `v0.0.13`

Per [`docs/roadmap/v0.1.0-plan.md`](../roadmap/v0.1.0-plan.md),
CanaryUI + windowed presentation: a backend-neutral UI abstraction
bootstrapped on `egui` (ADR 0011), a real window-to-renderer
presentation seam, and the first game sample driven by the public
runtime frame loop.
